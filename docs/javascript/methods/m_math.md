# Методы встроенного класса `Math`

## Список методов `Math`:

```bash title="Возвращает абсолютное значение числа x."
Math.abs(x)
```

```bash title="Возвращает арккосинус числа x в радианах."
Math.acos(x)
```

```bash title="Возвращает гиперболический арккосинус числа x."
Math.acosh(x)
```

```bash title="Возвращает арксинус числа x в радианах."
Math.asin(x)
```

```bash title="Возвращает гиперболический арксинус числа x."
Math.asinh(x)
```

```bash title="Возвращает арктангенс числа x в радианах."
Math.atan(x)
```

```bash title="Возвращает гиперболический арктангенс числа x."
Math.atanh(x)
```

```bash title="Возвращает арктангенс частного y и x."
Math.atan2(y, x)
```

```bash title="Возвращает кубический корень числа x."
Math.cbrt(x)
```

```bash title="Округляет число x вверх до ближайшего целого."
Math.ceil(x)
```

```bash title="Возвращает количество ведущих нулевых битов в 32-битном двоичном представлении числа x."
Math.clz32(x)
```

```bash title="Возвращает косинус числа x (в радианах)."
Math.cos(x)
```

```bash title="Возвращает гиперболический косинус числа x."
Math.cosh(x)
```

```bash title="Возвращает e в степени x, где e — основание натуральных логарифмов."
Math.exp(x)
```

```bash title="Возвращает e^x - 1."
Math.expm1(x)
```

```bash title="Округляет число x вниз до ближайшего целого."
Math.floor(x)
```

```bash title="Возвращает ближайшее число с плавающей запятой одинарной точности, представляющее x."
Math.fround(x)
```

```bash title="Возвращает квадратный корень суммы квадратов аргументов."
Math.hypot([x[, y[, …]]])
```

```bash title="Возвращает результат C-like 32-битного умножения аргументов x и y."
Math.imul(x, y)
```

```bash title="Возвращает натуральный логарифм (по основанию e) числа x."
Math.log(x)
```

```bash title="Возвращает натуральный логарифм (по основанию e) от 1 + x."
Math.log1p(x)
```

```bash title="Возвращает логарифм числа x по основанию 10."
Math.log10(x)
```

```bash title="Возвращает логарифм числа x по основанию 2."
Math.log2(x)
```

```bash title="Возвращает наибольшее из нуля или более чисел."
Math.max([x[, y[, …]]])
```

```bash title="Возвращает наименьшее из нуля или более чисел."
Math.min([x[, y[, …]]])
```

```bash title="Возвращает x возведенное в степень y."
Math.pow(x, y)
```

```bash title="Возвращает псевдослучайное число между 0 (включительно) и 1 (не включая 1)."
Math.random()
```

```bash title="Округляет число x до ближайшего целого."
Math.round(x)
```

```bash title="Возвращает знак числа x, указывая, является ли x положительным, отрицательным или нулем."
Math.sign(x)
```

```bash title="Возвращает синус числа x (в радианах)."
Math.sin(x)
```

```bash title="Возвращает гиперболический синус числа x."
Math.sinh(x)
```

```bash title="Возвращает положительный квадратный корень числа x."
Math.sqrt(x)
```

```bash title="Возвращает тангенс числа x (в радианах)."
Math.tan(x)
```

```bash title="Возвращает гиперболический тангенс числа x."
Math.tanh(x)
```

```bash title="Возвращает строку, представляющую исходный код объекта Math. Этот метод не стандартизирован и не рекомендуется к использованию."
Math.toSource()
```

```bash title="Возвращает целую часть числа x, удаляя любые дробные цифры."
Math.trunc(x)
```

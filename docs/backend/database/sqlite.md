**SQLite** — это лёгкая реляционная система управления базами данных (СУБД), которая хранит данные в одном файле и не требует отдельного сервера.

Для работы с базой данных используется язык **SQL (Structured Query Language)**.

Основные возможности SQLite:

- Создание и изменение таблиц.
- Добавление, получение, обновление и удаление данных.
- Поиск, фильтрация и сортировка записей.
- Объединение данных из нескольких таблиц.
- Группировка данных и выполнение вычислений.

В примерах ниже используется таблица `users` с полями `id`, `name`, `age` и `email`.

***

### **CREATE (Создание таблицы)**

Команда `CREATE TABLE` используется для создания новой таблицы в базе данных.

**Синтаксис:**

```sql
CREATE TABLE table_name (
    column1 datatype,
    column2 datatype,
    column3 datatype
);
```

**Пример:**

```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    age INTEGER,
    email TEXT UNIQUE
);
```

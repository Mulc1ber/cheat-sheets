# **Полезные команды и описания SQLite**

## **Описание**

**SQLite** — это лёгкая реляционная система управления базами данных (СУБД), которая хранит данные в одном файле и не требует отдельного сервера.

Для работы с базой данных используется язык **SQL (Structured Query Language)**.

Основные возможности SQLite:

- Создание и изменение таблиц.
- Добавление, получение, обновление и удаление данных.
- Поиск, фильтрация и сортировка записей.
- Объединение данных из нескольких таблиц.
- Группировка данных и выполнение вычислений.

В примерах ниже используется таблица `users` с полями `id`, `name`, `age` и `email`.

***

## **CREATE (Создание таблицы)**

Команда `CREATE TABLE` используется для создания новой таблицы в базе данных.

**Синтаксис:**

```sql
CREATE TABLE table_name (
    column1 datatype,
    column2 datatype,
    column3 datatype
);
```

**Пример:**

```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    age INTEGER,
    email TEXT UNIQUE
);
```

**Описание параметров:**

| Параметр      | Описание                            |
| ------------- | ----------------------------------- |
| `INTEGER`     | Целое число                         |
| `TEXT`        | Текстовые данные                    |
| `REAL`        | Число с плавающей точкой            |
| `BLOB`        | Двоичные данные                     |
| `NULL`        | Отсутствие значения                 |
| `PRIMARY KEY` | Первичный ключ таблицы              |
| `NOT NULL`    | Запрещает значение NULL             |
| `UNIQUE`      | Запрещает повторение значений       |
| `DEFAULT`     | Устанавливает значение по умолчанию |
| `CHECK`       | Проверяет условие для значения      |

**Полезная команда:**

```sql
CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL
);
```

`IF NOT EXISTS` предотвращает ошибку, если таблица уже существует.

## **ALTER (Изменение таблицы)**

Команда `ALTER TABLE` позволяет изменять структуру существующей таблицы.

**Добавление нового столбца:**

```sql
ALTER TABLE users
ADD COLUMN phone TEXT;
```

Добавляет столбец `phone` в таблицу `users`.

**Переименование столбца:**

```sql
ALTER TABLE users
RENAME COLUMN name TO username;
```

Переименовывает `name` в `username`.

**Переименование таблицы:**

```sql
ALTER TABLE users
RENAME TO customers;
```

**Удаление столбца:**

```sql
ALTER TABLE users
DROP COLUMN phone;
```

Доступно начиная с SQLite 3.35.0. Удаление может быть запрещено, если столбец используется в ограничениях или других элементах схемы.

> В SQLite возможности `ALTER TABLE` ограничены. Например, для изменения типа существующего столбца часто требуется пересоздать таблицу.

## **INSERT (Вставка данных)**

Команда `INSERT INTO` используется для добавления новых записей в таблицу.

**Добавление одной записи:**

```sql
INSERT INTO users (name, age, email)
VALUES ('Alex', 25, 'alex@mail.com');
```

**Добавление нескольких записей:**

```sql
INSERT INTO users (name, age, email)
VALUES
    ('Ivan', 20, 'ivan@mail.com'),
    ('Maria', 23, 'maria@mail.com'),
    ('Oleg', 30, 'oleg@mail.com');
```

**Добавление записи с заполнением только некоторых столбцов:**

```sql
INSERT INTO users (name, age)
VALUES ('Anna', 22);
```

Неуказанные столбцы получат значение по умолчанию или `NULL`, если это разрешено.

**Полезная команда:**

```sql
INSERT OR IGNORE INTO users (name, email)
VALUES ('Alex', 'alex@mail.com');
```

`OR IGNORE` позволяет пропустить вставку при некоторых нарушениях ограничений, например `UNIQUE`, вместо возникновения ошибки.

## **SELECT (Вывод данных)**

Команда `SELECT` используется для получения данных из таблицы.

**Вывести все данные:**

```sql
SELECT * FROM users;
```

`*` означает выбор всех столбцов.

**Вывести определённые столбцы:**

```sql
SELECT name, age FROM users;
```

**Вывести данные по условию:**

```sql
SELECT * FROM users
WHERE age > 18;
```

**Несколько условий:**

```sql
SELECT * FROM users
WHERE age >= 18 AND age <= 30;
```

**Сортировка:**

```sql
SELECT * FROM users
ORDER BY age DESC;
```

- `ASC` — по возрастанию (по умолчанию).
- `DESC` — по убыванию.

**Ограничение количества записей:**

```sql
SELECT * FROM users
LIMIT 5;
```

**Пропуск записей:**

```sql
SELECT * FROM users
LIMIT 5 OFFSET 10;
```

Пропускает первые 10 строк и возвращает следующие 5. Для предсказуемого результата следует использовать `ORDER BY`.

**Уникальные значения:**

```sql
SELECT DISTINCT age FROM users;
```

Убирает дублирующиеся значения из результата.

### **Операторы WHERE**

| Оператор      | Описание                       |
| ------------- | ------------------------------ |
| `=`           | Равно                          |
| `!=` или `<>` | Не равно                       |
| `>`           | Больше                         |
| `<`           | Меньше                         |
| `>=`          | Больше или равно               |
| `<=`          | Меньше или равно               |
| `AND`         | Логическое И                   |
| `OR`          | Логическое ИЛИ                 |
| `NOT`         | Логическое НЕ                  |
| `IN`          | Значение входит в список       |
| `BETWEEN`     | Значение находится в диапазоне |
| `IS NULL`     | Проверка на NULL               |
| `IS NOT NULL` | Проверка на отсутствие NULL    |

**Примеры:**

```sql
SELECT * FROM users
WHERE age IN (18, 20, 25);
```

```sql
SELECT * FROM users
WHERE age BETWEEN 18 AND 30;
```

```sql
SELECT * FROM users
WHERE email IS NOT NULL;
```

## **UPDATE (Обновление данных)**

Команда `UPDATE` используется для изменения существующих записей.

**Изменение одного значения:**

```sql
UPDATE users
SET age = 26
WHERE id = 1;
```

Изменяет возраст пользователя с `id = 1`.

**Изменение нескольких значений:**

```sql
UPDATE users
SET name = 'Alexander',
    age = 27
WHERE id = 1;
```

**Обновление по условию:**

```sql
UPDATE users
SET age = age + 1
WHERE age < 18;
```

Увеличивает возраст на 1 для всех пользователей младше 18 лет.

**Важно:** если не указать `WHERE`, изменения затронут все строки таблицы.

```sql
UPDATE users
SET age = 18;
```

## **DELETE (Удаление данных)**

Команда `DELETE` используется для удаления записей из таблицы.

**Удаление одной записи:**

```sql
DELETE FROM users
WHERE id = 1;
```

**Удаление по условию:**

```sql
DELETE FROM users
WHERE age < 18;
```

**Удаление всех записей:**

```sql
DELETE FROM users;
```

Удаляет все строки, но сохраняет структуру таблицы.

**Удаление таблицы полностью:**

```sql
DROP TABLE users;
```

Удаляет таблицу вместе с её данными и структурой.

**Безопасное удаление:**

Перед удалением рекомендуется проверить записи:

```sql
SELECT * FROM users
WHERE age < 18;
```

После проверки выполнить:

```sql
DELETE FROM users
WHERE age < 18;
```

## **JOIN (Объединение таблиц)**

`JOIN` используется для объединения данных из двух или нескольких таблиц по связанным столбцам.

Предположим, есть две таблицы:

**users**

| id | name  |
| -- | ----- |
| 1  | Alex  |
| 2  | Ivan  |
| 3  | Maria |

**orders**

| id | user_id | product  |
| -- | ------- | -------- |
| 1  | 1       | Laptop   |
| 2  | 1       | Mouse    |
| 3  | 2       | Keyboard |

### **INNER JOIN**

Возвращает только записи, для которых найдены совпадения в обеих таблицах.

```sql
SELECT users.name, orders.product
FROM users
INNER JOIN orders
ON users.id = orders.user_id;
```

**Результат:**

| name | product  |
| ---- | -------- |
| Alex | Laptop   |
| Alex | Mouse    |
| Ivan | Keyboard |

### **LEFT JOIN**

Возвращает все записи из левой таблицы и совпадающие записи из правой.

```sql
SELECT users.name, orders.product
FROM users
LEFT JOIN orders
ON users.id = orders.user_id;
```

**Результат:**

| name  | product  |
| ----- | -------- |
| Alex  | Laptop   |
| Alex  | Mouse    |
| Ivan  | Keyboard |
| Maria | NULL     |

### **Другие виды JOIN**

| Тип               | Описание                             |
| ----------------- | ------------------------------------ |
| `INNER JOIN`      | Только совпадающие записи            |
| `LEFT JOIN`       | Все записи слева и совпадения справа |
| `RIGHT JOIN`      | Все записи справа и совпадения слева |
| `FULL OUTER JOIN` | Все записи обеих таблиц              |
| `CROSS JOIN`      | Все возможные комбинации строк       |

`RIGHT JOIN` и `FULL OUTER JOIN` поддерживаются начиная с SQLite 3.39.0.

**Псевдонимы таблиц:**

```sql
SELECT u.name, o.product
FROM users AS u
JOIN orders AS o
ON u.id = o.user_id;
```

`AS` позволяет использовать короткие имена таблиц для удобства.

## **LIKE (Поиск по шаблону)**

Оператор `LIKE` используется для поиска текстовых значений по определённому шаблону.

**Специальные символы:**

| Символ | Описание                                |
| ------ | --------------------------------------- |
| `%`    | Любое количество символов, включая ноль |
| `_`    | Ровно один любой символ                 |

**Поиск по началу строки:**

```sql
SELECT * FROM users
WHERE name LIKE 'A%';
```

Найдёт имена, начинающиеся на `A`.

**Поиск по концу строки:**

```sql
SELECT * FROM users
WHERE name LIKE '%a';
```

Найдёт имена, заканчивающиеся на `a`.

**Поиск по части строки:**

```sql
SELECT * FROM users
WHERE name LIKE '%lex%';
```

Найдёт строки, содержащие `lex`.

**Поиск по количеству символов:**

```sql
SELECT * FROM users
WHERE name LIKE 'A___';
```

Найдёт имена из четырёх символов, начинающиеся с `A`.

**Исключение совпадений:**

```sql
SELECT * FROM users
WHERE name NOT LIKE 'A%';
```

По умолчанию `LIKE` в SQLite не учитывает регистр для латинских ASCII-символов (`A–Z`), но обычно учитывает регистр для кириллицы и других Unicode-символов.

## **Дополнительные полезные команды SQLite**

### **COUNT, SUM, AVG, MIN, MAX (Агрегатные функции)**

Используются для подсчётов и вычислений.

| Функция   | Описание              |
| --------- | --------------------- |
| `COUNT()` | Количество записей    |
| `SUM()`   | Сумма значений        |
| `AVG()`   | Среднее значение      |
| `MIN()`   | Минимальное значение  |
| `MAX()`   | Максимальное значение |

```sql
SELECT COUNT(*) FROM users;
```

Подсчитать количество пользователей.

```sql
SELECT AVG(age) FROM users;
```

Найти средний возраст.

```sql
SELECT MIN(age), MAX(age) FROM users;
```

Найти минимальный и максимальный возраст.

### **GROUP BY (Группировка)**

Группирует записи по указанному столбцу.

```sql
SELECT age, COUNT(*) AS total
FROM users
GROUP BY age;
```

Показывает количество пользователей каждого возраста.

### **HAVING (Фильтрация групп)**

Используется для фильтрации результатов после `GROUP BY`.

```sql
SELECT age, COUNT(*) AS total
FROM users
GROUP BY age
HAVING COUNT(*) > 2;
```

Выводит только те возрастные группы, в которых больше двух пользователей.

**Разница:**

- `WHERE` — фильтрует отдельные строки до группировки.
- `HAVING` — фильтрует группы после группировки.

### **CREATE INDEX (Создание индекса)**

Индексы позволяют ускорять поиск и фильтрацию данных по определённым столбцам.

```sql
CREATE INDEX idx_users_age
ON users(age);
```

Создаёт индекс для столбца `age`.

```sql
DROP INDEX idx_users_age;
```

Удаляет индекс.

Индексы могут ускорять чтение, но занимают дополнительное место и могут замедлять вставку и обновление данных.

### **PRAGMA (Информация и настройки SQLite)**

**Посмотреть структуру таблицы:**

```sql
PRAGMA table_info(users);
```

**Посмотреть список таблиц:**

```sql
SELECT name
FROM sqlite_master
WHERE type = 'table';
```

**Посмотреть индексы таблицы:**

```sql
PRAGMA index_list(users);
```

**Проверить внешние ключи:**

```sql
PRAGMA foreign_keys;
```

**Включить проверку внешних ключей:**

```sql
PRAGMA foreign_keys = ON;
```

Настройка применяется к текущему соединению с базой данных. Её следует включать вне активной транзакции.

### **TRANSACTION (Транзакции)**

Транзакции позволяют выполнять несколько операций как единое целое.

```sql
BEGIN TRANSACTION;

UPDATE users
SET age = 25
WHERE id = 1;

UPDATE users
SET age = 30
WHERE id = 2;

COMMIT;
```

- `BEGIN` — начало транзакции.
- `COMMIT` — сохранение изменений.
- `ROLLBACK` — отмена изменений незавершённой транзакции.

| `OFFSET`       | Пропуск строк                 |

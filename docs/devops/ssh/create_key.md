# Команды по созданию ssh ключа

Описание

---

### Создание SSH ключа базовая команда

```bash
ssh-keygen
```

> _Данная команда создаст ключи: `id_rsa` (приватный ключ) и `id_rsa.pub` (публичный ключ)_

### Полезные параметры ssh-keygen

- `-t` - тип ключа (rsa, ed25519, ecdsa)
- `-b` - длина ключа (для RSA)
- `-f` - путь и имя файла
- `-C` - комментарий (обычно email)
- `-N` - парольная фраза

### Создание SSH ключа в новом формате `OpenSSH`

```bash
ssh-keygen -o
```

Инструкция далее:

- Путь сохранения: Нужно будет указать где сохранить файл или нажмите Enter, чтобы согласиться с предложенным по умолчанию путём (указывая пусть, можно сразу переименовать ключ).
- Парольная фраза (Passphrase): Предложат ввести пароль для защиты приватного ключа.
- Готово: После подтверждения будут созданы два файла: `id_rsa` (приватный ключ в новом формате OpenSSH) и `id_rsa.pub` (публичный ключ).

### Создание именованных SSH ключей

```bash
ssh-keygen -f ~/.ssh/github
```

Создаст ключи:

- github (приватный)
- github.pub (публичный)

### Создание ключа с указанием типа и имени

```bash title=""
ssh-keygen -t rsa -b 4096 -f ~/.ssh/имя_ключа -C "комментарий"
```

Примеры:

```bash title="Для GitHub"
ssh-keygen -t ed25519 -f ~/.ssh/github -C "your_email@example.com"
```

```bash title="Для рабочего сервера"
ssh-keygen -t rsa -b 4096 -f ~/.ssh/work_server -C "work_access"
```

```bash title="Для личного использования"
ssh-keygen -t ed25519 -f ~/.ssh/personal -C "personal_projects"
```

### Проверка созданных ключей

```bash title="Посмотреть список ключей"
ls -la ~/.ssh/
```

```bash title="Проверить отпечаток ключа"
ssh-keygen -lf ~/.ssh/имя_ключа
```

### Созданные ключи нужно добавить в SSH-агент командой

```bash title="Команда для доступа к ssh ключу"
ssh-add <путь_до_публичного_ключе_без_расширения_.pub>
```

```bash title="Пример"
ssh-add ~/.ssh/github
```

## Справочная информация

### Что такое OpenCode

OpenCode — это **открытый AI‑агент для разработки**, работающий в терминале (TUI — Text User Interface). Он призван интегрировать возможности ИИ прямо в привычную среду программиста — без необходимости переключаться между IDE, браузером и чатами с нейросетями.

Создан командой Anomaly (авторами terminal.shop) как альтернатива закрытым решениям вроде Claude Code — с акцентом на гибкость, независимость от вендоров и полный контроль над данными.

![Interface OpenCode in terminal](./img/InterfaceOpenCode.png)

### Ключевые особенности

1. **Провайдер‑независимость**:
   - поддерживает API от OpenAI, Anthropic (Claude), Google (Gemini) и других;
   - работает с локальными моделями через Ollama, LM Studio и т. д.;
   - интегрируется с агрегаторами вроде Open Router (доступ к 75+ провайдерам).

2. **Клиент‑серверная архитектура**:
   - сервер можно запустить на мощном ПК или удалённом сервере;
   - клиент — на слабом устройстве (ультрабуке, планшете, смартфоне).

3. **Глубокая интеграция с кодом**:
   - использует Language Server Protocol (LSP) — понимает синтаксис, связи между файлами, предупреждения линтеров;
   - анализирует весь проект целиком, а не отдельные фрагменты.

4. **Мультиагентная система**:
   - разные «агенты» для разных задач (build, debug, architect и т. д.);
   - быстрое переключение между ними клавишей Tab.

5. **Автономия действий**:
   - может редактировать файлы, создавать новые, удалять старые;
   - запускает bash‑команды (например, `npm run test`, `cargo build`) для проверки кода.

6. **Открытый исходный код** (open‑source):
   - сообщество может вносить изменения, предлагать функции, исправлять баги;
   - нет привязки к конкретному вендору или платной подписке.

7. **Оптимизация для терминала**:
   - интерфейс спроектирован для работы без мыши (горячие клавиши, как в Neovim);
   - низкий overhead — быстрее IDE‑расширений на 20–40 %.

8. **Графический интерфейс (GUI)**:
   - есть бета‑версия десктоп‑приложения для Windows, macOS, Linux;
   - упрощает настройку API‑ключей, просмотр diff‑ов кода, переключение агентов.

### Возможности (на примере агента build)

Представьте, что вы даёте задачу: _«Реализуй корзину покупок с использованием Redis, обнови docker‑compose и напиши юнит‑тесты»_. OpenCode:

1. анализирует текущую архитектуру проекта;
2. генерирует нужные файлы и вносит правки (в виде diff‑блоков);
3. предлагает подтвердить изменения;
4. запускает `npm test` или `pytest`, чтобы проверить работоспособность кода.

## Установка (кратко)

**Универсальный способ (через npm)**:

```bash
npm i -g opencode-ai@latest
```

**macOS/Linux (через Homebrew)**:

```bash
brew install anomalyco/tap/opencode
# или
brew install opencode
```

**Arch Linux**:

```bash
sudo pacman -S opencode
# или
paru -S opencode-bin
```

**Windows (через Scoop или Chocolatey)**:

```bash
scoop install opencode
# или
choco install opencode
```

После установки перейдите в папку проекта и запустите:

```bash
opencode
```

При первом запуске потребуется указать API‑ключ выбранной нейросети или настроить локальную модель.

## Команды в OpenCode

В OpenCode существует два типа команд, и их важно различать:

1.  **Слэш-команды (например, `/init`, `/models`)** — вводятся прямо в чате внутри TUI (текстового интерфейса) для управления сессией.
2.  **CLI-команды (например, `opencode --continue`)** — вводятся в обычном терминале (PowerShell, cmd) для управления программой извне.

### 📌 Слэш-команды TUI (вводятся в чате)

Эти команды работают, когда вы уже внутри OpenCode.

| Команда                   | Что делает                                                                                                                                                                              |
| :------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`/init`**               | **Сканирует ваш проект и создаёт файл `AGENTS.md`** в корне. Это не `git init`! AI будет использовать этот файл как контекст, чтобы понимать структуру, стиль и команды вашего проекта. |
| **`/models`**             | Показывает список **всех доступных AI-моделей** (через OpenRouter и другие провайдеры). Позволяет переключиться на другую модель прямо во время сессии .                                |
| **`/new`**                | Начинает **новую сессию**, очищая текущий контекст диалога .                                                                                                                            |
| **`/sessions`**           | Показывает список **всех сохранённых сессий**, чтобы вы могли вернуться к любому предыдущему диалогу .                                                                                  |
| **`/undo` / `/redo`**     | Отменяет или повторяет последнее действие. OpenCode делает скрытые коммиты в Git, позволяя "откатить" код и сообщение .                                                                 |
| **`/share` / `/unshare`** | Публикует текущий диалог по **публичной ссылке** (удобно для демонстрации или просьбы о помощи) .                                                                                       |
| **`/editor`**             | Открывает **внешний редактор** (например, VS Code) для написания длинных или сложных промтов .                                                                                          |
| **`/export`**             | Экспортирует **текущую сессию в JSON-файл** (для резервного копирования или анализа) .                                                                                                  |
| **`/themes`**             | Показывает список доступных тем оформления интерфейса .                                                                                                                                 |
| **`/help`**               | Показывает краткую справку по всем доступным командам .                                                                                                                                 |
| **`/connect`**            | Открывает интерфейс подключения провайдеров (OpenRouter, OpenAI и т.д.) и добавления API-ключей.                                                                                        |
| **`/agents`**             | Показывает список доступных AI-агентов — специализированных ролей для AI. Позволяет переключаться между ними.                                                                           |
| **`/exit`**               | Полностью завершает работу OpenCode и закрывает TUI.                                                                                                                                    |
| **`/mcps`**               | Управляет подключениями к серверам по протоколу MCP (Model Context Protocol).                                                                                                           |
| **`/review`**             | Запускает процесс код-ревью.                                                                                                                                                            |
| **`/skills`**             | Отображает список подключённых навыков (skills) — предварительно написанных инструкций, которые расширяют возможности AI.                                                               |
| **`/status`**             | Показывает текущее состояние сессии или всей системы OpenCode.                                                                                                                          |

**Создание своих команд**: Вы можете создавать собственные слэш-команды (например, `/test`, `/deploy`), поместив `.md` файлы с инструкцией для AI в папку `.opencode/command/` вашего проекта .

### ⚙️ CLI-команды (вводятся в терминале)

Эти команды запускают или управляют OpenCode из оболочки.

| Команда / Флаг                             | Что делает                                                                       |
| :----------------------------------------- | :------------------------------------------------------------------------------- |
| **`opencode`**                             | Запускает OpenCode в интерактивном режиме (TUI) в текущей папке .                |
| **`opencode --continue`** (или `-c`)       | **Возобновляет последнюю сессию** после закрытия терминала .                     |
| **`opencode --session <ID>`** (или `-s`)   | Возобновляет **конкретную сессию** по её ID .                                    |
| **`opencode --model <модель>`** (или `-m`) | Запускает OpenCode, **сразу используя указанную модель** .                       |
| **`opencode --prompt "текст"`** (или `-p`) | Запускает OpenCode и **отправляет запрос** неинтерактивно (быстрое выполнение) . |
| **`opencode models`**                      | **Список всех моделей** от подключённых провайдеров (прямо в терминале) .        |
| **`opencode run <сообщение>`**             | **Неинтерактивный запуск**: выполняет один запрос и завершает работу .           |
| **`opencode web`**                         | Запускает **веб-интерфейс** OpenCode (локальный сервер в браузере) .             |
| **`opencode serve`**                       | Запускает **фоновый сервер** для API-доступа к OpenCode .                        |
| **`opencode auth`**                        | Управляет **учётными данными** (API-ключами провайдеров) .                       |
| **`opencode agent`**                       | Управляет **агентами** (список, создание, настройка) .                           |
| **`opencode upgrade`**                     | Обновляет OpenCode до последней версии .                                         |

### 🤖 Агенты (интеллектуальные роли)

Это не команды, а **специализированные режимы AI**, которые можно вызывать через `@имя_агента` или через команды.

| Агент                      | Роль                                                                                    | Когда использовать                                               |
| :------------------------- | :-------------------------------------------------------------------------------------- | :--------------------------------------------------------------- |
| **`build`** (по умолчанию) | **Разработчик** с полным доступом: читает, пишет, редактирует код и запускает команды . | Строительство фич, рефакторинг, исправление багов.               |
| **`plan`**                 | **Планировщик** (только чтение): не может ничего изменять, только анализирует .         | Код-ревью, архитектурный анализ перед изменениями.               |
| **`@general`**             | **Исследователь**: ищет паттерны и решает сложные вопросы по кодовой базе .             | Автоматически или через `@general найти все обработчики ошибок`. |

**Как использовать**: Переключаться между `build` и `plan` можно клавишей **Tab** прямо во время диалога.

### 🏃 Примеры рабочих связок

- **Начать новый проект с полным анализом**:

  ```bash
  opencode --model openrouter/google/gemma-4-31b-it:free
  ```

  - Внутри TUI: `/init` → `@plan Как мне реорганизовать API?` → `Tab` → `build` → `/models` (поменять на другую модель).

- **Вернуться к вчерашней работе**:

  ```bash
  opencode --continue
  ```

- **Возобновление диалога по ID**

  ```bash
  opencode --session abc123-def456-7890
  ```

- **Создать свою быструю команду** (`/fix`):
  Создайте файл `.opencode/command/fix.md`:

  ```markdown
  ---
  description: Исправляет ошибки линтера в текущем файле
  ---

  Проанализируй открытый файл и исправь все ошибки линтинга, следуя стилю кода из @AGENTS.md
  ```

  Теперь в чате можно просто написать `/fix` .

### **Коротко о главном**

- `/init` **обучает** AI вашему проекту;
- `/models` **меняет мозги** ассистента;
- `opencode --continue` **возвращает** вас к работе после перерыва.
- `build`/`plan` — это разные режимы работы: первый меняет код, второй только советует.

Список команд

Перемещение файлов​

mv 1.txt my_folder/

Вывод информации о правах папки или файлов​

1. Команды ls и la​

ls -ld my_folder/

Вывод покажет: drwxr-xr-x (права) + владельца и группу

Описание флагов:

  • -l — подробный вывод
  • -d — показывает информацию о самой папке, а не о её содержимом
ls -la my_folder/

Покажет права для всех файлов и папок в текущей директории, где первая колонка содержит информацию о правах доступа.

Описание флагов:

  • -l — подробный вывод
  • -a — показывает информацию о содержимом папки, включая о правах доступа

2. Команда stat​

stat my_folder

Показывает права в числовом (например, 0755) и буквенном формате.

3. Чтение символического обозначения прав​

Буквенная запись drwxr-xr-x расшифровывается так:

Первый символ:

  • d — directory (папка)
  • - — обычный файл
  • l — symbolic link

Далее 3 группы по 3 символа:

  • Владелец (user): rwx = read, write, execute
  • Группа (group): r-x = read, execute (без write)
  • Остальные (others): r-x = read, execute

Примеры:

  • rwx = все права (7 в числовом формате)
  • r-x = чтение и выполнение (5)
  • r-- = только чтение (4)
  • --- = нет прав (0)

4. Права вложенных файлов​

ls -lR имя_папки/

Покажет права для всей папки рекурсивно.

Изменение прав на папку или файл​

Основной синтаксис:

chmod [опции] права имя_папки

1. Символьный (буквенный) формат​

Структура: [ugoa][+-=][rwxXst]

Кто:

  • u — владелец (user)
  • g — группа (group)
  • o — остальные (others)
  • a — все (all, по умолчанию)

Действие:

  • + — добавить право
  • - — убрать право
  • = — установить точно

Права:

  • r — чтение
  • w — запись
  • x — выполнение (для папок — вход)
  • X — выполнение только если это папка или уже есть право x

Примеры символьного формата:​

Дать всем полные права:

chmod a+rwx my_folder
# или
chmod ugo+rwx my_folder

Дать владельцу полные права, группе — чтение и выполнение, остальным — только выполнение:

chmod u=rwx,g=rx,o=x my_folder

Добавить право на выполнение для всех:

chmod a+x my_folder

Убрать право на запись у группы и остальных:

chmod go-w my_folder

Дать право на запись владельцу:

chmod u+w my_folder

2. Числовой (восьмеричный) формат​

Структура: три цифры (например, 755)

  • Первая цифра — владелец
  • Вторая — группа
  • Третья — остальные

Цифры:

  • 4 = r (чтение)
  • 2 = w (запись)
  • 1 = x (выполнение)
  • 0 = нет прав

Комбинации:

  • 7 = 4+2+1 = rwx
  • 6 = 4+2 = rw-
  • 5 = 4+1 = r-x
  • 4 = 4 = r--
  • 0 = ---

Примеры числового формата:​

Стандартные права для папки (владелец — всё, остальные — чтение и выполнение):

chmod 755 my_folder

Что равно: rwxr-xr-x

Более строгие права (только владелец):

chmod 700 my_folder

Что равно: rwx------

Только чтение для всех:

chmod 444 my_folder

Что равно: r--r--r--

3. Рекурсивное изменение прав​

Для изменения прав на папку и всё её содержимое

Рекурсивно для папки и всех вложенных файлов/папок:

chmod -R 755 my_folder/

Рекурсивно добавить право на выполнение для папок (но не файлов):

chmod -R a+X my_folder/

(флаг X вместо x применяет право x только к папкам)

4. Полезные опции​

Показать, что изменяется (verbose):

chmod -v 755 my_folder

Вывод: mode of 'my_folder' changed from 0750 to 0755

Изменять только папки (без файлов):

find my_folder -type d -exec chmod 755 {} \;

Изменять только файлы (без папок):

find my_folder -type f -exec chmod 644 {} \;

5. Типичные сценарии​

Стандартные права для веб-папки:

chmod 755 public_html/

Закрытая папка (только владелец):

chmod 700 private_data/

Общая папка для группы:

chmod 775 shared_folder/
chmod g+s shared_folder/  # + setgid для наследования группы

Безопасная конфигурация:

# Папки — 755
find /path -type d -exec chmod 755 {} \;

# Файлы — 644
find /path -type f -exec chmod 644 {} \;

# Исполняемые файлы — 755
find /path -type f -name "*.sh" -exec chmod 755 {} \;
